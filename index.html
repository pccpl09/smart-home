Arduino example for ESP32 + DHT22. It publishes temperature/humidity and receives MQTT commands to switch an LED.

การต่อวงจร Wiring

ต่อ GPIO ผ่านตัวต้านทาน 220–330 โอห์มเข้าขา Anode ของ LED และต่อขา Cathode ลง GND

Connect each GPIO through a 220–330 ohm resistor to the LED anode; connect the cathode to GND.

LEDขา Pico W Pico W GPIO
LED 1GP15
LED 2GP14
LED 3GP13

ใช้วงจรแรงดันต่ำเท่านั้น ห้ามต่อไฟบ้านหรือขดลวดรีเลย์เข้ากับขา GPIO โดยตรง

Use low-voltage circuits only. Never connect mains voltage or a relay coil directly to a GPIO pin.

ตัวอย่าง ESP32 + DHT22 ESP32 + DHT22 example

โค้ด Arduino เชื่อมต่อ Wi-Fi และ MQTT, ส่งอุณหภูมิ/ความชื้นทุก 3 วินาที และสมัครรับคำสั่งควบคุม LED ที่ GPIO2

The Arduino sketch connects to Wi-Fi and MQTT, publishes temperature/humidity every 3 seconds, and subscribes to LED commands on GPIO2.

การต่อ DHT22 DHT22 wiring

ต่อ DATA เข้าขา GPIO4, VCC เข้ากับไฟเลี้ยงตามรุ่นเซนเซอร์ และ GND เข้ากับ GND ของบอร์ด หากเป็น DHT22 แบบตัวเซนเซอร์เปล่า ให้ใช้ตัวต้านทาน pull-up ระหว่าง DATA กับ VCC ตามวงจรของโมดูล

Connect DATA to GPIO4, VCC to the supply supported by your sensor module, and GND to board ground. For a bare DHT22 sensor, add a pull-up resistor between DATA and VCC as required by its circuit.

LED และ Topic LED and topics

ตัวอย่างตั้งค่า LED ที่ GPIO2 (โดยทั่วไปคือ LED บนบอร์ดบางรุ่น) และรับ ON/OFF จาก classroom/<username>/control/led

The sketch uses GPIO2 for the LED (often the onboard LED on some boards) and accepts ON/OFF on classroom/<username>/control/led.

ข้อมูลเซนเซอร์ JSON ส่งไปที่ classroom/<username>/sensor/temp

Sensor JSON is published to classroom/<username>/sensor/temp.

ติดตั้งและอัปโหลด Install and upload

  1. ติดตั้ง ESP32 board support ใน Arduino IDE และไลบรารี PubSubClient, DHT sensor library ของ Adafruit และ Adafruit Unified Sensor

    Install ESP32 board support in Arduino IDE, plus PubSubClient, Adafruit's DHT sensor library, and Adafruit Unified Sensor.

  2. เปิด esp32_dht22_mqtt.ino แล้วแก้ WIFI_SSID, WIFI_PASSWORD, STUDENT_USERNAME และ MQTT_PASSWORD

    Open esp32_dht22_mqtt.ino and set WIFI_SSID, WIFI_PASSWORD, STUDENT_USERNAME, and MQTT_PASSWORD.

  3. เลือกบอร์ด ESP32 และพอร์ตอนุกรมที่ถูกต้อง จากนั้นอัปโหลดและเปิด Serial Monitor ที่ 115200 baud

    Select the correct ESP32 board and serial port, upload the sketch, and open Serial Monitor at 115200 baud.

Dashboard ในหน้านี้สั่ง LED 3 ช่องของ Pico W ผ่าน Topic control/led/1–/3 ส่วนตัวอย่าง ESP32 รับคำสั่ง LED เดียวที่ Topic control/led จึงใช้ปุ่มใน Dashboard นี้ควบคุม ESP32 โดยตรงไม่ได้

The dashboard on this page controls the Pico W's three LEDs using control/led/1–/3. The ESP32 example listens on the single topic control/led, so this dashboard does not directly control the ESP32 LED.

ติดตั้งและเริ่มใช้งาน Configure and run

  1. ติดตั้งเฟิร์มแวร์ MicroPython สำหรับ Raspberry Pi Pico W

    Install MicroPython firmware for the Raspberry Pi Pico W.

  2. คัดลอก umqtt/simple.py จากแพ็กเกจ micropython-lib ไปยังบอร์ดที่ /lib/umqtt/simple.py

    Copy umqtt/simple.py from micropython-lib to the board at /lib/umqtt/simple.py.

  3. แก้ค่า Wi-Fi, username และ MQTT password ใน pico_w_three_leds.py

    Set the Wi-Fi credentials, username, and MQTT password in pico_w_three_leds.py.

  4. อัปโหลดไฟล์ไปยัง Pico W โดยตั้งชื่อเป็น main.py

    Upload the program to the Pico W as main.py.

  5. เปิด Dashboard ในเบราว์เซอร์ กรอก username และ MQTT password เดียวกับในบอร์ด แล้วเชื่อมต่อ Broker 172.16.3.215

    Open the dashboard in a browser. Enter the same username and MQTT password configured on the board, then connect to broker 172.16.3.215.

รหัสผ่าน SFTP สำหรับบัญชีทดสอบตรงกับ username (ตัวอย่าง user1001) ส่วนรหัสผ่าน MQTT เป็นรหัสสุ่มแยกต่างหาก ให้ขอจากผู้ดูแลระบบ

For test accounts, the SFTP password matches the username (for example, user1001). The MQTT password is a separate random credential; request it from the administrator.

MQTT Topics

แต่ละบัญชีใช้ Topic ของตนเอง โดย Dashboard ส่งคำสั่ง และ Pico W ส่งสถานะกลับ

Each account uses its own topics. The dashboard publishes commands, and the Pico W publishes status updates.

คำสั่งควบคุม Commands

classroom/<username>/control/led/1

classroom/<username>/control/led/2

classroom/<username>/control/led/3

ส่งค่า ON หรือ OFF ไปยัง LED แต่ละดวง

Send ON or OFF to each LED.

สถานะ LED LED status

classroom/<username>/status/led/1

classroom/<username>/status/led/2

classroom/<username>/status/led/3

Pico W ส่งสถานะล่าสุดแบบ retained เพื่อให้ Dashboard อ่านค่าได้ทันที

The Pico W publishes retained status so the dashboard can read the latest state immediately.

สิทธิ์ MQTT จำกัดตาม ACL ให้แต่ละบัญชีเข้าถึง Topic ของตนเองเท่านั้น

MQTT ACLs restrict each account to its own topics.

เครือข่ายทดสอบนี้ใช้ MQTT พอร์ต 1883 และ WebSocket แบบไม่เข้ารหัสที่พอร์ต 9001 ใช้เฉพาะบน LAN ที่เชื่อถือได้

The classroom test broker uses unencrypted MQTT on port 1883 and WebSocket on port 9001. Use it only on a trusted LAN.
